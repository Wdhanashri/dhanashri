## Re-test protocol

1. **Don't read the row.** Just the question. Answer out loud, or rewrite the code cold.
2. Right → tick. Two consecutive ticks → the row retires.
3. Wrong again → that concept drops to **🔴** in `ledger.md`. A repeat means it was never learned.

## What your dominant tag means

| Tag | The fix — **not** "read it again" |
|---|---|
| `blank` | Genuine gap. Re-teach from the anchor. Normal and easiest to fix. |
| `vague` | You know it, can't say it. **Fix by speaking** — 60-second answers, timed, out loud. |
| `mixed-up` | Build a contrast table for the pair (composition/inheritance, Strategy/Factory, ABC/duck typing). |
| `no-why` | The important one. You're memorising. Write "because ___" for each and drill *that*. |
| `didnt-run` | Type the code yourself instead of reading it. Every time. |
