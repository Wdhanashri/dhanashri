## Quant

| Topic | Formula / shortcut |
|---|---|
| **Successive % change** | `a + b + ab/100` (use for discounts, CI, everything) |
| **A is x% more than B** | B is `x/(100+x) × 100` % less than A |
| **Profit / loss** | on **CP**. Discount on **MP**. |
| **Same SP, +x% and −x%** | **always a loss** of `x²/100 %` |
| **Alligation** | cross-difference → ratio of the two groups |
| **Average** | `avg × count = total`. Convert to total first. |
| **Average of 1..n** | `(n+1)/2` |
| **SI** | `P·R·T/100` |
| **CI (2 yr)** | use successive %: 10% twice = 21% |
| **CI − SI, 2 yr** | `P(R/100)²` |
| **km/hr → m/s** | `× 5/18` (reverse: `× 18/5`) |
| **Avg speed, equal distance** | `2xy/(x+y)` — never the plain average |
| **Avg speed, equal time** | `(x+y)/2` |
| **Speed ratio a:b** | time ratio `b:a` (same distance) |
| **Same direction / opposite** | `a−b` / `a+b` |
| **Train past pole / platform** | own length / train + platform |
| **Boat** | down `b+s`, up `b−s`; `b=(d+u)/2`, `s=(d−u)/2` |
| **Time & work** | **total = LCM of days**, then rates are whole numbers |
| **Leak / emptying pipe** | negative rate |
| **M₁D₁ = M₂D₂** | men–days proportion |
| **LCM × HCF** | = product of the two numbers |
| **nPr / nCr** | order matters / doesn't. `nCr = nC(n−r)` |
| **Circular arrangement** | `(n−1)!` |
| **X must sit together** | glue them: `(n−1)! × 2` |
| **"At least one"** | `1 − P(none)` |

**Divisibility:** 4 → last 2 digits · 8 → last 3 · 3,9 → digit sum · 11 → (odd places) − (even places)

**Unit digit cycles (mod 4):** 2→2,4,8,6 · 3→3,9,7,1 · 7→7,9,3,1 · 8→8,4,2,6 · 4→4,6 · 9→9,1 · 0,1,5,6→itself

## Reasoning

**Series — run this order:** differences → differences of differences → ratios → squares/cubes ± k → alternating → ×n ± k → primes

**Coding:** check the **first letter** first. Types: shift · reverse · opposite (positions sum to **27**) · word-substitution · A=1..Z=26

**Blood relations:** draw it. **Read the phrase backwards.**

**Directions:** redraw the arrow after **every** turn. Right = clockwise.

**Syllogism:**
```
All A are B  →  "Some B are A" ✓   ·   "All B are A" ✗
Some A are B →  "Some B are A" ✓
No A are B   →  "No B are A"   ✓
Some A not B →  "Some B not A" ✗    ← the trap
```
A conclusion follows only if it holds in **every** possible drawing.

**Clock:** `angle = |30H − 5.5M|` (if >180, subtract from 360). Hands overlap **22×/day**.

**Calendar:** ordinary year **1** odd day · leap **2** · 100 yr **5** · 200 **3** · 300 **1** · 400 **0**. Century leap only if ÷400.

**Puzzles:** start with the **most definite** clue, never clue 1. Can't fix a position in 2 min → leave the set.

## Verbal

**The 8 rules:** subject–verb agreement · each/every/neither → singular · tense consistency · preposition pairs · a/an by sound · parallelism · misplaced modifier · pronoun agreement

**The one that appears every time:** *along with · as well as · including · in addition to* **do not change the subject's number.**
> "The captain, along with the players, **is** here."

**Preposition pairs:** different **from** · superior/inferior **to** · married **to** · comprises (no *of*) · since (point) vs for (duration)

**Unknown word:** context (+/−) → roots → eliminate → **guess**

**Prefixes:** mal- bad · bene- good · anti/contra- against · circum- around · omni- all · pseudo- false · eu- good · a/an- without

**RC:** questions first → skim for structure → go back and find the line → never use outside knowledge.
Wrong answers are **too extreme** ("always", "all"), **too narrow**, or **outside scope**.

**Para jumbles:** the opener never starts with a pronoun or a connector. Find one **mandatory pair** and eliminate options.

## ⭐ The exam itself — read this last

```
PASS 1  (50% of time)  the obvious ones. Nothing over 60 seconds.
PASS 2  (35%)          the skipped ones that now look doable.
PASS 3  (15%)          fill EVERY blank with a guess.
```

- **90-second rule:** no method in 90 seconds → mark it and move. You are deciding *"do I know the method"*, not *"can I solve it"*.
- **Never leave a blank.** No negative marking = blank and wrong score the same.
- **Eliminate two, then guess.** That's a 50% shot, and it adds up over 25 questions.
- **DI sets as a block** — one chart understood is 4–5 fast marks.
- **Watch sectional cut-offs.** A perfect quant won't rescue a failed verbal.
- **The most expensive question is the medium one you won't let go of.**
