## ① C-44 · The state question

**Anchor:** *"Say `dp[i]` in one English sentence. If you can't, you don't have the problem yet."*

**This is the habit that separates people who solve DP from people who pattern-match it.** Before any code:

```
dp[i] = " ______________________________ "     ← fill this in, in English
```

| Problem | `dp[i]` means |
|---|---|
| Climbing Stairs | the number of ways to reach step `i` |
| House Robber | the most money robbable from the first `i` houses |
| Coin Change | the fewest coins that make amount `i` |
| Word Break | whether `s[:i]` can be fully segmented |

**Once that sentence exists, the recurrence writes itself** — because you know exactly what you're combining.

### Coin Change

> `dp[a]` = **the fewest coins that make amount `a`.**

```
amount 6, coins [1, 3, 4]

to make 6, try each coin as the LAST one:
    use 1 → 1 + dp[5]
    use 3 → 1 + dp[3]
    use 4 → 1 + dp[2]
    dp[6] = min of those
```

```python
dp = [float("inf")] * (amount + 1)
dp[0] = 0                                  # zero coins make zero
for a in range(1, amount + 1):
    for c in coins:
        if a - c >= 0:
            dp[a] = min(dp[a], 1 + dp[a - c])
return dp[amount] if dp[amount] != float("inf") else -1
```

**`inf` is the "impossible" marker.** `1 + inf` stays `inf`, so impossibility propagates on its own — no special-casing needed. That's why `inf` rather than `-1` as the initial value.

### Word Break

> `dp[i]` = **can `s[:i]` be fully segmented?**

```python
dp = [False] * (len(s) + 1)
dp[0] = True                               # empty string: trivially yes
for i in range(1, len(s) + 1):
    for w in wordDict:
        if i >= len(w) and s[i-len(w):i] == w and dp[i - len(w)]:
            dp[i] = True
            break
return dp[len(s)]
```

Read the condition as one sentence: *"a word ends here, **and** everything before it was already segmentable."* Both halves are required.

**The Gotcha:** `dp[0]` is the base case in both, and both times it means *"the empty case, which is trivially fine"* — 0 coins, empty string. **Getting `dp[0]` wrong breaks everything downstream** and the failure looks random.

**Recall:** *Before writing any DP code, what's the one thing you write down?*
