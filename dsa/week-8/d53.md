## ① C-45 · Expand around centre

**Anchor:** *"Stand at the middle and push outwards."*

NeetCode files these under DP. **The expand-around-centre solution is simpler and faster to write** — and knowing when *not* to use DP is worth as much as knowing when to.

```
"babad"

every position is a potential centre. There are 2n−1 of them:

  b a b a d
  ↑         odd centre  (single char)
  ↑↑        even centre (between two chars)

from each centre, push left and right while the characters match
```

```python
def longest_palindrome(s):
    res = ""
    for i in range(len(s)):
        for l, r in ((i, i), (i, i + 1)):        # odd centre, even centre
            while l >= 0 and r < len(s) and s[l] == s[r]:
                if r - l + 1 > len(res):
                    res = s[l:r+1]
                l -= 1
                r += 1
    return res
```

**O(n²) time, O(1) space** — and the DP table version is also O(n²) time but O(n²) *space*. So this is strictly better, and shorter to write under pressure.

**The two centres are the whole trick.** `"aba"` has a single-character middle; `"abba"` has a gap between two characters. Handle both by seeding `(i, i)` and `(i, i+1)`.

**Counting palindromic substrings is the same loop** — instead of tracking the longest, add 1 for every successful expansion:

```python
count = 0
for i in range(len(s)):
    for l, r in ((i, i), (i, i + 1)):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            count += 1
            l -= 1
            r += 1
```

**The Gotcha:** forgetting the even centre. `"abba"` then returns `"a"`, and half your test cases pass — which makes it a slow bug to find.

**Recall:** *Expand around centre — how many centres are there, and why not just n?*

## ② Say this in an interview

> *"I could do this with a DP table, but expand-around-centre is the same O(n²) time with O(1) space and it's quicker to write. There's also Manacher's algorithm for O(n) — I wouldn't code it here, but it exists."*

**That sentence does three things at once:** shows you know the alternative, shows you chose deliberately, and shows you know where the ceiling is. It's a strong thing to have ready, and it costs one line.
