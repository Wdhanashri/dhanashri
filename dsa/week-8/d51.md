## ① The take-or-skip recurrence

**Anchor:** *"At every position: take it and jump two, or skip it and move one."*

**House Robber.** This shape reappears constantly — learn it as a shape, not as a problem.

```
houses:  [2, 7, 9, 3, 1]

at house i:
   TAKE  →  money[i] + best(i + 2)      can't touch i+1
   SKIP  →           best(i + 1)

   best(i) = max(take, skip)
```

```python
@cache
def rob(i):
    if i >= len(nums): return 0
    return max(nums[i] + rob(i + 2),      # take
               rob(i + 1))                 # skip
```

**Bottom-up, then trimmed to O(1):**
```python
prev2 = prev1 = 0
for n in nums:
    prev2, prev1 = prev1, max(prev1, n + prev2)
return prev1
```

**Read the trimmed version as the same two options:** `prev1` is "best so far having skipped this", `n + prev2` is "best having taken it". The `max` is the decision.

**The Gotcha:** the "skip" branch is `rob(i+1)`, **not** `rob(i+2)`. Skipping a house doesn't stop you taking the next one — only *taking* imposes the gap. Getting this wrong gives plausible-looking answers on small inputs.

**Recall:** *House Robber — what are the two options at house i, and which one jumps two?*

## ② The circle trick

**House Robber II** — the houses form a circle, so the first and last are adjacent.

```
circle:  you can never take BOTH house 0 and house n-1

so:      answer = max( rob(houses[1:]),      ← exclude the first
                       rob(houses[:-1]) )     ← exclude the last
```

**Run the same function twice on two slices, take the max.** That's the entire solution.

**Why it's complete:** any valid selection must exclude the first house, the last house, or both. Both those cases are covered by the two runs — and "both excluded" is inside each of them.

**The transferable move:** *when one constraint links the two ends, split into two straight-line problems.* You'll see this again with circular arrays generally.

**The Gotcha:** the single-house edge case. `houses[1:]` and `houses[:-1]` are both empty when `n == 1`, so handle `len(nums) == 1` before splitting.

**Recall:** *House Robber II — why does running it twice cover every case?*
