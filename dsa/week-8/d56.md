## Part C · The transfer test — 20 min ⭐

**This is the most important part of this gate.** A problem you have not seen:

> **Given a staircase and an array `cost[]`, you may climb 1, 2 **or 3** steps at a time. Return the minimum cost to reach the top.**

**Do not code it yet.** On paper, in this order:

```
1. dp[i] = " ______________________________ "      (English)
2. base case(s)
3. the recurrence
4. THEN write the memoised version
```

<details><summary>Check — open only after you've written all four</summary>

1. `dp[i]` = the minimum cost to reach step `i`.
2. `dp[0] = dp[1] = dp[2] = 0` (you can start free), or handle `i < 0` → `inf`.
3. `dp[i] = cost[i] + min(dp[i-1], dp[i-2], dp[i-3])`
4. Same as Min Cost Climbing Stairs with a third option.
</details>

**Pass:** you produced the English sentence and a correct recurrence **before** looking. Whether the code compiles matters less — the four steps are the skill.

> Getting this right means DP transferred. Getting the twelve solutions right without this would only mean you remembered twelve solutions.
