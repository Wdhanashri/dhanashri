## ② 🔵 Stretch problems — only if the ledger is clean

*Advanced Graphs* on **neetcode.io/practice**.

| NeetCode | Problem | Ask yourself | Cap |
|---|---|---|---|
| AG 1 | Reconstruct Itinerary | *You must use every ticket exactly once. What kind of path is that?* | 35m |
| AG 5 | Alien Dictionary | *A letter order derived from word comparisons. What algorithm orders things by dependency?* | 35m |

**AG 1 — Eulerian path.** Visit every *edge* once (not every node). Sort each destination list so you take the lexicographically smallest first, then DFS and **append to the answer on the way back up**, reversing at the end. That post-order append is the trick.

**AG 5 — this is topological sort (C-36).** Compare adjacent words, find the first differing letter → that's an edge. Then Kahn's. Two edge cases everyone misses:
```
"abc" before "ab"    → invalid, return ""     (prefix must come first)
a cycle in the order → invalid, return ""     (your length check catches this)
```
Recognising it as topological sort under a disguise is the whole skill here.
