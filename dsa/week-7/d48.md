## ① Multiply Strings — the position rule

**Anchor:** *"digit i × digit j lands at positions i+j and i+j+1."*

```
      1 2 3        indices 0 1 2   (m = 3)
    × 4 5 6        indices 0 1 2   (n = 3)
    ─────────
    result has at most m + n = 6 digits

    num1[i] * num2[j]  →  carry into result[i+j],  digit into result[i+j+1]
                          (working with both numbers REVERSED)
```

```python
def multiply(num1, num2):
    if num1 == "0" or num2 == "0":
        return "0"

    m, n = len(num1), len(num2)
    res = [0] * (m + n)
    num1, num2 = num1[::-1], num2[::-1]        # reverse: index = place value

    for i in range(m):
        for j in range(n):
            digit = int(num1[i]) * int(num2[j])
            res[i + j] += digit
            res[i + j + 1] += res[i + j] // 10   # carry up
            res[i + j] %= 10

    res = res[::-1]
    return "".join(map(str, res)).lstrip("0")
```

**Two things to have ready:**
```
length ≤ m + n        99 × 99 = 9801 → 2+2 = 4 digits. Never more.
strip leading zeros   the array is pre-sized, so unused slots are 0
```

**The Gotcha:** reverse both strings first, so that **array index = place value**. Trying it un-reversed means every index becomes `m-1-i`, and the arithmetic gets unreadable.

**Recall:** *Multiplying digit i by digit j — which two result positions are involved?*
