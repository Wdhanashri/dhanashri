## ① C-41 · Matrix & math tricks

**Anchor:** *"These aren't algorithms. They're index tricks you either know or don't."*

Be honest about what this block is: there's no deep idea to derive. **Learn the three moves, drill them, move on.**

### Rotate 90° clockwise = transpose, then reverse each row

```
1 2 3      transpose      1 4 7      reverse rows      7 4 1
4 5 6   ───────────────►  2 5 8   ────────────────►    8 5 2
7 8 9   (swap i,j)        3 6 9    (each row)          9 6 3
```

```python
n = len(matrix)
for i in range(n):                      # transpose
    for j in range(i + 1, n):           # ← j starts at i+1, or you undo it
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
for row in matrix:                      # reverse each row
    row.reverse()
```
**Anticlockwise:** transpose, then reverse the *column order* (i.e. reverse the list of rows).

### Spiral — four boundaries that close in

```
    left ─────────────► right
top  ┌─────────────────┐
     │  →  →  →  →  →  │      go right along `top`,   then top++
     │  ┌───────────►  │      go down  along `right`,  then right--
     │  ↑           ↓  │      go left  along `bottom`, then bottom--
     │  └───────────┘  │      go up    along `left`,   then left++
bottom └────────────────┘     repeat while top <= bottom and left <= right
```

**The Gotcha:** after the right-to-left and bottom-to-top passes, re-check `top <= bottom` and `left <= right` **inside** the loop. A single leftover row otherwise gets traversed twice.

### Set Matrix Zeroes — mark first, write second

```
❌ zero a row as you scan  →  those new zeros trigger MORE zeroing. Cascade.
✅ pass 1: record which rows and columns need zeroing
   pass 2: apply it
```
Two sets is O(m+n) space and perfectly acceptable. The O(1) version uses row 0 and column 0 as the marker storage — **mention it exists**, code the simple one first.

**The Gotcha:** the cascade. Zeroing in place makes the input lie to you mid-scan, and the answer looks *almost* right — which is worse than obviously wrong.

**Recall:** *Rotate 90° clockwise — the two operations, in order?*
