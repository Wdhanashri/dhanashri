## ① Concept C-23 · The BST invariant

**Anchor:** *"Every node lives inside a (low, high) window."*
**Yaad rakho:** *"Har node apni hadd ke andar rehta hai."*

```
                  (5)          window: (−∞, +∞)
                ↙     ↘
             (3)       (8)     left: (−∞, 5)      right: (5, +∞)
            ↙   ↘
         (1)     (4)           (−∞, 3)   (3, 5)
```

Every node inherits a range from **everything above it**, not just its parent.

### The mistake almost everyone makes

```python
# WRONG
if node.left.val < node.val < node.right.val:   # only checks neighbours
```

Here's why it fails:

```
        5
       / \
      3   8
         / \
       (2)  9      ← 2 < 8 ✓ so a local check passes
                      but 2 is on the RIGHT of 5, so it must be > 5. NOT A BST.
```

The constraint comes from an **ancestor**, and yesterday's rule says: *info from above → parameter.* (C-21, already earning its keep.)

```python
def is_valid_bst(root):
    def valid(node, low, high):
        if not node: return True
        if not (low < node.val < high): return False
        return valid(node.left, low, node.val) and \
               valid(node.right, node.val, high)
    return valid(root, float("-inf"), float("inf"))
```

Read the recursive line aloud: *"going left, I become the new ceiling; going right, I become the new floor."*

## ② The second BST fact

**An inorder traversal of a BST comes out sorted.** Left → node → right.

```
        5
       / \          inorder:  1, 3, 4, 5, 8
      3   8                   └─ sorted, for free
     / \
    1   4
```

So "kth smallest" needs no sorting at all — walk inorder and stop at the kth node:

```python
def kth_smallest(root, k):
    stack, cur = [], root
    while stack or cur:
        while cur:                       # go as far left as possible
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        k -= 1
        if k == 0: return cur.val        # ← stop the moment you're done
        cur = cur.right
```

**Gotcha:** don't build the full sorted list and index it. That throws away the BST property you were being tested on — and interviewers notice.

## ③ Walking down a BST

Lowest Common Ancestor of a BST. No recursion needed — just walk down:

```
both values SMALLER than me  →  go left
both values BIGGER  than me  →  go right
otherwise (they split here)  →  I AM the answer
```

```python
def lowest_common_ancestor(root, p, q):
    cur = root
    while cur:
        if p.val < cur.val and q.val < cur.val:   cur = cur.left
        elif p.val > cur.val and q.val > cur.val: cur = cur.right
        else: return cur                          # the split point
```

**Why the split point is the answer:** the first node where they diverge is the last node they share. O(height), O(1) space.
