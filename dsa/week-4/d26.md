## ① Concept C-24 · Global vs returned

**Anchor:** *"What you report ≠ what you return."*

Remember D22's discomfort? Here's the name for it.

Some problems ask about a path that **passes through** a node but doesn't continue upward. So there are two different numbers at every node:

```
                (10)
               ↙    ↘
            (2)      (10)
                        ↘
                        (−25)

at node 10 (root):
   the ANSWER through me   = leftBest + rightBest + my value      → global max
   what my PARENT can use  = my value + max(leftBest, rightBest)  → returned

   Why? A parent can only extend ONE branch through me —
   it can't use both, or the path would fork.
```

**The recipe:**

```python
best = <worst possible>       # module-level or nonlocal

def dfs(node):
    if not node: return 0
    L, R = dfs(node.left), dfs(node.right)
    best = max(best, <answer through this node>)   # ① RECORD
    return <what the parent can extend>            # ② RETURN
```

Two lines, two different expressions. **Diameter, max path sum, longest univalue path** — all this exact shape.

## ② The hardest tree problem · Max Path Sum

Same recipe, one extra idea.

```
1. Answer through me:  node.val + leftGain + rightGain
2. Return to parent:   node.val + max(leftGain, rightGain)
3. NEW: what if a branch is negative?
```

**You are allowed to simply not take a branch.** A negative subtree contributes `0`, not its negative value:

```python
def max_path_sum(root):
    best = float("-inf")

    def gain(node):
        nonlocal best
        if not node: return 0
        L = max(gain(node.left), 0)          # ← negative? take nothing.
        R = max(gain(node.right), 0)
        best = max(best, node.val + L + R)   # ① through me (can fork here)
        return node.val + max(L, R)          # ② upward (one branch only)

    gain(root)
    return best
```

**`max(gain(child), 0)` is the whole extra idea.** Say it out loud: *"if a branch hurts, don't take it."*

## ③ Info travelling down · Count Good Nodes

A node is "good" if nothing on the path from the root is bigger than it.

**Which direction does the information travel?** The max-so-far comes from *above* → **parameter** (C-21 again — third day running).

```python
def good_nodes(root):
    def dfs(node, max_so_far):
        if not node: return 0
        count = 1 if node.val >= max_so_far else 0
        max_so_far = max(max_so_far, node.val)         # updated on the way down
        return count + dfs(node.left, max_so_far) + dfs(node.right, max_so_far)
    return dfs(root, root.val)
```

**Max-so-far travels down as a parameter. The count travels up as a return value.** Both directions, one function — exactly what C-21 predicted.
