## ① Concept C-25 · Serialize with null markers

**Anchor:** *"Preorder + `N` for empty = a unique string."*

Turn a tree into a string, then back. **Why preorder alone fails:**

```
    1            preorder: 1, 2
     \
      2

    1            preorder: 1, 2      ← IDENTICAL. Two different trees.
     /
    2
```

Add explicit nulls and the ambiguity disappears:

```
    1   →  "1,2,N,N,N"          (right child of 1 is null)
     \
      2

    1   →  "1,2,N,N,N"  ... wait — now write the second tree:
     /
    2      →  "1,2,N,N,N"  for the left version the null pattern differs:
                left version:  1, 2, N, N, N
                right version: 1, N, 2, N, N     ← different. Unambiguous. ✓
```

```python
def serialize(root):
    out = []
    def dfs(node):
        if not node:
            out.append("N"); return
        out.append(str(node.val))
        dfs(node.left); dfs(node.right)
    dfs(root)
    return ",".join(out)

def deserialize(data):
    vals = data.split(",")
    i = 0
    def dfs():
        nonlocal i
        if vals[i] == "N":
            i += 1; return None
        node = TreeNode(int(vals[i]))
        i += 1
        node.left = dfs()               # same preorder order, so the index lines up
        node.right = dfs()
        return node
    return dfs()
```

**Gotcha:** `i` must be shared across all recursive calls — hence `nonlocal`. Pass it as an argument and each call gets its own copy, and the whole thing silently breaks.

## ② The other way to rebuild · Preorder + Inorder

```
preorder: [3, 9, 20, 15, 7]      first element is ALWAYS the root
inorder:  [9, 3, 15, 20, 7]      the root SPLITS this into left | right

root = 3
find 3 in inorder at index 1:

   inorder:  [9] | 3 | [15, 20, 7]
              ↑         ↑
           left subtree  right subtree     ← now recurse on each
```

```python
def build_tree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}     # value -> position, O(1) lookup
    self_i = 0

    def build(lo, hi):
        nonlocal self_i
        if lo > hi: return None
        val = preorder[self_i]; self_i += 1
        node = TreeNode(val)
        mid = idx[val]
        node.left  = build(lo, mid - 1)             # LEFT FIRST — preorder demands it
        node.right = build(mid + 1, hi)
        return node

    return build(0, len(inorder) - 1)
```

**Two gotchas:**
1. Build **left before right** — preorder consumes in that order, so swapping them corrupts everything.
2. The `idx` dict turns an O(n) search into O(1), making the whole thing O(n) instead of O(n²). *That's C-01 — the hash map trade — 27 days later.*
