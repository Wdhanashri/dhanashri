## ① C-55 · XOR cancels pairs

**Anchor:** *"`a ^ a = 0`. XOR everything and the pairs disappear."*

```
[4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1^1) ^ (2^2)        XOR is commutative and associative
= 4 ^ 0 ^ 0
= 4                        ← the loner survives
```

```python
res = 0
for n in nums:
    res ^= n
return res
```

**Three XOR facts, and they solve four problems between them:**
```
a ^ a = 0          a pair cancels
a ^ 0 = a          identity
order doesn't matter
```

**Missing Number** — the same trick: XOR all the indices *and* all the values. Every number that's present cancels with its index, leaving the one that's missing.

## ② C-56 · The bit tricks worth memorising

**Anchor:** *"`n & (n-1)` clears the lowest set bit."*

```
   n     = 12 = 1100
   n - 1 = 11 = 1011        subtracting 1 flips the lowest 1 and everything
   n&(n-1)=  8 = 1000       below it → the AND clears exactly that bit
```

| Trick | Does | Use |
|---|---|---|
| `n & (n-1)` | clears the lowest set bit | count bits · check power of two |
| `n & 1` | is it odd? | last bit |
| `n >> 1` | divide by 2 | walk the bits |
| `n & -n` | isolates the lowest set bit | — |
| `1 << i` | the i-th bit | build a mask |
| `n ^ 1` | flips the last bit | — |

**Number of 1 Bits** — loop `n &= n - 1` and count. It runs once per *set* bit, not 32 times.

**Power of two:** `n > 0 and n & (n-1) == 0` — a power of two has exactly one set bit, so clearing it gives zero.

**Counting Bits** — DP meets bits:
```python
dp = [0] * (n + 1)
for i in range(1, n + 1):
    dp[i] = dp[i >> 1] + (i & 1)     # bits of i//2, plus i's last bit
```
**That's a DP recurrence** — `dp[i]` built from a smaller subproblem. Week 8 arriving in a bit problem.

**Reverse Bits** — 32 iterations, pull the last bit off `n`, push it onto the result:
```python
res = 0
for i in range(32):
    res = (res << 1) | (n & 1)
    n >>= 1
return res
```

**The Gotcha (Python-specific, and it will bite):** Python integers are **arbitrary precision** and negatives don't behave like fixed-width two's complement. For Sum of Two Integers and Reverse Integer you must mask to 32 bits:
```python
mask = 0xFFFFFFFF
a = a & mask
if a > 0x7FFFFFFF:            # it's meant to be negative
    a = ~(a ^ mask)
```
**Say this out loud in an interview** — *"in Python I'd need to mask to 32 bits because integers don't overflow"* is a detail almost nobody mentions.

**Recall:** *What does `n & (n-1)` do, and what two problems does it solve?*
