## ① C-54 · Interval sorting

**Anchor:** *"Sort by START to merge. Sort by END to keep the most."*

**That contrast is the entire section.** Two problems that look identical need opposite sorts.

```
MERGE (sort by start)              KEEP MAX (sort by END)
 ├────┤                             ├────┤
    ├─────┤   → ├────────┤             ├──────────┤
              ├──┤                        ├──┤

 overlap? extend the end            greedily keep whatever finishes FIRST —
                                    it leaves the most room for the rest
```

### Merge Intervals

```python
intervals.sort(key=lambda x: x[0])              # by START
merged = [intervals[0]]
for start, end in intervals[1:]:
    if start <= merged[-1][1]:                  # overlaps the last one
        merged[-1][1] = max(merged[-1][1], end) # extend it
    else:
        merged.append([start, end])
return merged
```

**`max` on the extension matters** — a fully-contained interval `[1,10]` then `[2,3]` must not shrink the end back to 3.

### Non-overlapping Intervals — sort by END

```python
intervals.sort(key=lambda x: x[1])              # by END
count, prev_end = 0, intervals[0][1]
for start, end in intervals[1:]:
    if start >= prev_end:
        prev_end = end                          # no overlap: keep it
    else:
        count += 1                              # overlap: remove this one
return count
```

**Why sorting by end is safe** — and this is the justification you'll be asked for:

> *"The interval that finishes earliest leaves the most room for everything after it. So keeping it can never be worse than keeping any alternative."*

That's the classic activity-selection argument, and it's worth having word-perfect.

### Insert Interval — three phases

```
1. everything ending BEFORE the new one starts   → append unchanged
2. everything overlapping                        → absorb into the new one
                                                   (min of starts, max of ends)
3. everything left                               → append unchanged
```

**The Gotcha:** *sort by start* and *sort by end* give different answers to problems that look the same. **Decide which before you write anything**, and say why out loud.

**Recall:** *Sort by start or by end — which for merging, which for keeping the most, and why?*
