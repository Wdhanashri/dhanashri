## ① Meeting Rooms I — can one room do it?

Sort by start, then check every adjacent pair:

```python
intervals.sort(key=lambda x: x[0])
for i in range(1, len(intervals)):
    if intervals[i][0] < intervals[i-1][1]:
        return False           # this one starts before the last one ended
return True
```

Five lines. **The only subtlety is `<` vs `<=`** — a meeting ending at 10 and one starting at 10 don't clash. Ask the interviewer; assume they don't.

## ② Meeting Rooms II — the sweep line

**Anchor:** *"Rooms needed = the most meetings overlapping at any single moment."*

That reframe is the whole problem. **Two ways, both worth knowing.**

### Way A · two sorted lists (the sweep)

```
meetings: [0,30] [5,10] [15,20]

starts: 0, 5, 15          walk both lists in time order:
ends:  10, 20, 30

  t=0   start → rooms 1   (max 1)
  t=5   start → rooms 2   (max 2)   ← the answer
  t=10  end   → rooms 1
  t=15  start → rooms 2
  ...
```

```python
starts = sorted(i[0] for i in intervals)
ends   = sorted(i[1] for i in intervals)

rooms = best = s = e = 0
while s < len(starts):
    if starts[s] < ends[e]:
        rooms += 1; s += 1              # a meeting begins
    else:
        rooms -= 1; e += 1              # a meeting ends
    best = max(best, rooms)
return best
```

**You deliberately break the pairing.** Which meeting ends doesn't matter — only that *a* room freed up. Realising the pairing is irrelevant is the insight.

### Way B · a min-heap of end times

```python
intervals.sort(key=lambda x: x[0])
h = []                                   # end times of meetings in progress
for start, end in intervals:
    if h and h[0] <= start:
        heapq.heappop(h)                 # the earliest-ending room is free
    heapq.heappush(h, end)
return len(h)                            # rooms still in use = rooms needed
```

**That's your Week 5 heap** — *"which meeting frees up first?"* is a changing question, which is exactly C-26's test.

**The Gotcha:** in Way A, `rooms` goes *down* on an end event. Only tracking the maximum matters; the running value is allowed to fall.

**Recall:** *Meeting Rooms II — what number are you actually computing?*
