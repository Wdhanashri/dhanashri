## Part C · The unseen problem — 25 min ⭐

**This is the real test.** A problem not in NC150:

> **Given an array of integers and an integer `k`, return the number of contiguous subarrays whose sum equals `k`.**
> (Negatives are allowed.)

**Before coding, on paper — 5 minutes:**
```
1. What's the brute force, and its complexity?
2. What work is being repeated?
3. Which of your 15 algorithms fits? Name it.
4. THEN code it.
```

<details><summary>Check — open only after you've written all four</summary>

1. Every subarray: O(n²).
2. Recomputing sums that share a prefix.
3. **Hashing + prefix sum** — algorithm 1, from Week 1. Negatives rule out sliding window (the sum isn't monotonic), which is the trap.
4. ```python
   count = total = 0
   seen = {0: 1}                    # one way to have a prefix sum of 0
   for n in nums:
       total += n
       count += seen.get(total - k, 0)
       seen[total] = seen.get(total, 0) + 1
   return count
   ```
   `seen[0] = 1` is the base case — subarrays starting at index 0.
</details>

**Pass:** you named the right algorithm in step 3 **before** looking, and explained why sliding window fails.

> Ten weeks ago you couldn't do step 3 at all. That step — not the code — is what an interview measures.
