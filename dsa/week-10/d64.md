## ① C-52 · Kadane's algorithm

**Anchor:** *"If the running sum goes negative, it's a burden. Drop it."*

```
[-2, 1, -3, 4, -1, 2, 1]

cur:  -2 → drop (negative, can only hurt what comes next)
       1
      -2 → drop
       4
       3
       5
       6 ← best
```

```python
def max_subarray(nums):
    best = cur = nums[0]
    for n in nums[1:]:
        cur = max(n, cur + n)         # ← start fresh, or extend
        best = max(best, cur)
    return best
```

**`max(n, cur + n)` is the entire algorithm.** Read it as a question: *"is what I've built so far helping me, or would I be better off starting here?"* A negative prefix can only reduce whatever follows, so you abandon it.

**The Gotcha:** initialise `best` to `nums[0]`, **not** `0`. With all-negative input, starting at 0 returns 0 — an empty subarray, which isn't allowed. This is the test case that catches most submissions.

**Is it greedy or DP?** Both, honestly — `cur` is `dp[i]` = "best subarray ending at i", and you keep one variable instead of an array. **Say that if asked**; it shows you see the connection to D54's LIS shape.

**Recall:** *Kadane — what does `max(n, cur + n)` decide, and why not initialise `best` to 0?*

## ② The greedy reach

**Jump Game.** Can you reach the end? Don't explore routes — **track the furthest index reachable so far.**

```
[2, 3, 1, 1, 4]
 i=0  reach = 0+2 = 2
 i=1  reach = max(2, 1+3) = 4   ← already covers the end
 i=2  reach = max(4, 2+1) = 4
 ...  reach >= last index → True

if ever  i > reach  → you're standing past everything reachable → False
```

```python
reach = 0
for i, n in enumerate(nums):
    if i > reach:  return False        # stranded
    reach = max(reach, i + n)
return True
```

**Jump Game II** — the *minimum* number of jumps. Same idea, but track the current jump's window:

```python
jumps = l = r = 0
while r < len(nums) - 1:
    farthest = max(i + nums[i] for i in range(l, r + 1))
    l, r = r + 1, farthest             # the next jump's window
    jumps += 1
return jumps
```

**Read it as levels:** `[l, r]` is everything reachable in `jumps` jumps. That's BFS on an array — and noticing that is a good thing to say.

**The Gotcha:** `while r < len(nums) - 1`, not `<=`. Landing exactly on the last index means you're done; one more iteration counts a jump you never made.

**Recall:** *Jump Game — what single number replaces exploring every route?*
