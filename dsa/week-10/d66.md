## ① Merge Triplets — filter first, then check

```
target = [2, 7, 5]

a triplet is USABLE only if every element is <= the target
    [3, 4, 5]  → 3 > 2  → UNUSABLE. Merging it can never be undone.
    [2, 5, 3]  → fine
    [1, 7, 5]  → fine

among the usable ones, can you find a 2 in position 0, a 7 in position 1,
a 5 in position 2?  →  yes → True
```

```python
good = set()
for t in triplets:
    if any(t[i] > target[i] for i in range(3)):
        continue                              # ← unusable, skip entirely
    for i in range(3):
        if t[i] == target[i]:
            good.add(i)
return len(good) == 3
```

**The key realisation:** `max` only ever goes **up**, so a single oversized element poisons the result permanently. Filter those out first, and the rest is a simple coverage check.

## ② Valid Parenthesis String — track a range

`*` can be `(`, `)`, or nothing. Trying all three is 3ⁿ. **Track the range of possible open-counts instead.**

```
"(*)"

char   lo (if every * is ")")    hi (if every * is "(")
 (           1                        1
 *           0                        2        ← lo can't go below 0
 )          -1 → 0                    1

end: lo == 0  → valid ✓
```

```python
lo = hi = 0
for c in s:
    if c == "(":   lo += 1; hi += 1
    elif c == ")": lo -= 1; hi -= 1
    else:          lo -= 1; hi += 1     # '*' could be either
    if hi < 0:  return False            # too many ')' even in the best case
    lo = max(lo, 0)                     # can't have negative open brackets
return lo == 0
```

**Two lines carry it:**
```
hi < 0        → even the most generous reading has too many ')'. Dead.
lo = max(lo,0) → a negative "open count" is meaningless; clamp it
```

**The Gotcha:** the clamp. Without `lo = max(lo, 0)`, a `*` early in the string drives `lo` negative and it never recovers, so valid strings get rejected.

**The transferable move:** *when each choice is small and independent, track the **range** of outcomes instead of enumerating them.*

**Recall:** *Valid Parenthesis String — what do `lo` and `hi` represent?*
