## ① C-53 · The greedy proof

**Anchor:** *"Greedy works when the local best can never be regretted. Say why, or don't use it."*

**The question you will be asked is not "what's your algorithm" — it's "why does that work?"** Have the reason ready before you code.

| Problem | The greedy choice | Why it's safe |
|---|---|---|
| Gas Station | restart after any failing prefix | if you can't reach D from A, you can't from anything between A and D either |
| Hand of Straights | always start a group at the smallest card | the smallest card can't extend anything — it *must* begin a group |
| Partition Labels | cut when you pass every letter's last occurrence | a letter appearing later would force a merge, so no earlier cut is legal |
| Jump Game | track the furthest reach | reaching further can never be worse |

**Each "why" is one sentence.** Learn the sentence, not just the code — the code is short and the sentence is what's scored.

### Gas Station

```python
if sum(gas) < sum(cost):  return -1        # globally impossible

total = start = 0
for i in range(len(gas)):
    total += gas[i] - cost[i]
    if total < 0:                          # failed somewhere in [start .. i]
        start = i + 1                      # ← so skip ALL of them
        total = 0
return start
```

**Why the skip is safe:** if the running total went negative at `i`, then **no** station between `start` and `i` can be a valid start either — each one begins with even less fuel in hand. That single sentence is the whole justification, and it's what turns "I memorised this" into "I understand this."

### Partition Labels

```python
last = {c: i for i, c in enumerate(s)}     # last occurrence of every letter

res, size, end = [], 0, 0
for i, c in enumerate(s):
    size += 1
    end = max(end, last[c])
    if i == end:                           # nothing in this chunk appears later
        res.append(size)
        size = 0
return res
```

**Read `end` as "the earliest point I'm allowed to cut."** Every new letter can push it further; when you finally arrive at it, the cut is legal.

**The Gotcha:** greedy is the pattern people reach for *hoping* it works. **If you can't state the why in one sentence, it's probably DP.** Say that out loud in an interview and you'll sound careful rather than lucky.
