## ① The pattern behind both of today's problems

**Anchor:** *"When 'which one next?' changes every step, that's a heap."*

You've seen the heap as a *top-k* tool. Today it's a **scheduler** — the thing that repeatedly answers *"what now?"* as the answer keeps changing.

```
static question   →  sort once
changing question →  heap  ← re-answers in O(log n) after every update
```

**Task Scheduler:** the greedy move is *always run the most frequent remaining task* — because the rarest ones can fill gaps later, but the most frequent one is what forces the idle time.

**Design Twitter:** each user's tweets are already newest-first. Merging k sorted lists and taking the top 10 is a heap of k pointers — **the same shape as Merge K Sorted Lists** from Week 3's stretch set.

**The transferable move:** *"which is best right now?"* asked repeatedly, over a changing set, is always a heap.
