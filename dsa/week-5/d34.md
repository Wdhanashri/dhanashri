## ① C-31 · Pruning — the difference between passing and TLE

**Anchor:** *"Cut the branch the moment it cannot succeed."*

The template explores everything. **Pruning is what makes it finish.**

```
without pruning:   explore all 2ⁿ branches, discard bad ones at the leaves
with pruning:      kill a branch at the first sign it's dead

              [ ]
          ┌────┴────┐
       total=9      ...
          ✗ target is 7 → STOP HERE
            never explore this subtree at all
```

**The three prune checks, in the order you should write them:**

```python
def bt(...):
    if <complete>:        res.append(path[:]); return   # 1. success
    if <impossible>:      return                        # 2. prune — write this SECOND
    for choice in ...:                                  # 3. explore
```

| Situation | Prune when |
|---|---|
| Combination Sum | `total > target` |
| N-Queens | this column/diagonal is already attacked |
| Word Search | the current letter doesn't match |
| Palindrome Partitioning | the prefix isn't a palindrome |

**The Gotcha:** the prune check goes **before** the loop, not inside it. Checking inside means you've already paid for the recursive call you're about to reject.

## ② Backtracking on a grid

The choices are now **four directions** instead of list positions, and you need one extra move.

```python
def exist(board, word):
    rows, cols = len(board), len(board[0])

    def bt(r, c, i):
        if i == len(word):                       return True    # found it
        if r < 0 or c < 0 or r >= rows or c >= cols:  return False
        if board[r][c] != word[i]:               return False    # PRUNE

        board[r][c] = "#"                        # CHOOSE — mark visited
        found = (bt(r+1, c, i+1) or bt(r-1, c, i+1)
              or bt(r, c+1, i+1) or bt(r, c-1, i+1))
        board[r][c] = word[i]                    # UN-CHOOSE — restore it

        return found

    return any(bt(r, c, 0) for r in range(rows) for c in range(cols))
```

**The two marked lines are `path.append` and `path.pop` in disguise.** Marking the cell `#` *is* the choice; restoring it *is* the un-choose. Same template, different container.

**The Gotcha:** you must restore the cell. Leave it as `#` and a later starting position finds a corrupted board — and the failure looks like a wrong answer, not a crash.

**Recall:** *In grid backtracking, what plays the role of `path.append` and `path.pop`?*
