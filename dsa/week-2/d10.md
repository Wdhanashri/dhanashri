## ① Concept C-10 · Window + frequency map

**Anchor:** *"The map is the window's memory."*

Find the smallest substring of `s` containing every character of `t` (with counts).

```
s = "ADOBECODEBANC",  t = "ABC"        →  answer: "BANC"
```

```
1. Brute force:  every substring, check if it covers t.       O(n² · k)
2. The waste:    I recheck coverage from scratch every time.
3. What kills it: a window + a map that REMEMBERS coverage as it changes.
```

### Think it through — the key decision

You need to know "does my window cover `t` yet?" The obvious way:

```python
if have == need:     # compare two whole dicts... every single step
```

That's O(26) per move and it buries the logic. **Better: track one integer.**

```
need    = {A:1, B:1, C:1}       matched = how many chars have hit their target
have    = {}                    3 required, so matched == 3 means "covered"

add 'A' → have[A]=1 == need[A] → matched = 1
add 'B' → have[B]=1 == need[B] → matched = 2
add 'C' → have[C]=1 == need[C] → matched = 3   ← COVERED. now shrink.
```

`matched` goes up only when a character *exactly* hits its required count. Not before, not after.

### The code

```python
def min_window(s, t):
    if not t: return ""
    need = Counter(t)
    have = {}
    matched, required = 0, len(need)
    best = [-1, -1]
    l = 0

    for r in range(len(s)):
        c = s[r]
        have[c] = have.get(c, 0) + 1
        if c in need and have[c] == need[c]:
            matched += 1

        while matched == required:              # covered → try to shrink
            if best[0] == -1 or (r - l) < (best[1] - best[0]):
                best = [l, r]
            out = s[l]
            if out in need and have[out] == need[out]:
                matched -= 1                    # ① BEFORE the decrement
            have[out] -= 1                      # ②
            l += 1

    return s[best[0]:best[1]+1] if best[0] != -1 else ""
```

**Gotcha:** on shrink, decrement `matched` **before** `have[out]`. Do it the other way round and you've already broken the equality you're testing.
