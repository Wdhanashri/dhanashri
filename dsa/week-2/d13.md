## ① Concept C-13 · Stack for parsing

**Anchor:** *"Push operands, pop on operator."*

Reverse Polish Notation: `["2","1","+","3","*"]` → `(2+1)*3` = `9`.

```
push 2                    stack: [2]
push 1                    stack: [2, 1]
"+"  → pop 1, pop 2       compute 2+1 = 3 → push        stack: [3]
push 3                    stack: [3, 3]
"*"  → pop 3, pop 3       compute 3*3 = 9 → push        stack: [9]

answer = stack[0]
```

An operator always applies to the **two most recent** operands — the four stack words again: *most recent*.

```python
def eval_rpn(tokens):
    stack = []
    for t in tokens:
        if t == "+":   b, a = stack.pop(), stack.pop(); stack.append(a + b)
        elif t == "-": b, a = stack.pop(), stack.pop(); stack.append(a - b)
        elif t == "*": b, a = stack.pop(), stack.pop(); stack.append(a * b)
        elif t == "/": b, a = stack.pop(), stack.pop(); stack.append(int(a / b))
        else:          stack.append(int(t))
    return stack[0]
```

**Two gotchas, both worth marks:**

1. **Order.** The *first* pop is the **right** operand. `b, a = pop(), pop()` reads correctly: `a - b`. Get this backwards and `+`/`*` still pass while `-`/`/` fail — the worst kind of bug.
2. **Division.** Python's `//` floors toward −∞: `-7 // 2 == -4`. This problem wants truncation toward zero: `-3`. Use `int(a / b)`.

## ② The hard one · Largest Rectangle in Histogram

The toughest problem in Tier 1. It is still just C-12 — the monotonic stack — asked in a way that hides it.

**Think it through.** For each bar, ask: *how far left and right can a rectangle at this height stretch?*

```
      █                 A bar can extend outward until it meets
   █  █                 something SHORTER. So:
   █  █  █
█  █  █  █              width = (first shorter on the right)
─────────────                 − (first shorter on the left) − 1
2  5  6  4              ↑ "first shorter on each side" = monotonic stack
```

**The mechanism:** keep an *increasing* stack of `(start_index, height)`. When a shorter bar arrives, everything taller must close — and each one's rectangle stretches back to where it started.

```python
def largest_rectangle(heights):
    stack = []            # (start_index, height), increasing by height
    best = 0
    for i, h in enumerate(heights):
        start = i
        while stack and stack[-1][1] > h:
            idx, height = stack.pop()
            best = max(best, height * (i - idx))   # closes here, started at idx
            start = idx                            # ← I can extend back to there
        stack.append((start, h))

    for idx, height in stack:                      # bars that never closed
        best = max(best, height * (len(heights) - idx))
    return best
```

**The line that matters:** `start = idx`. When you pop a taller bar, *you* can extend back to where it began — because everything between you and it was at least as tall as you.
