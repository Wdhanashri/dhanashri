## ① Concept C-11 · Stack as memory

**Anchor:** *"For when the answer depends on the last unresolved thing."*

```
"( [ { } ] )"

push (   →  stack: (            a closer must match the TOP
push [   →  stack: ( [          nothing else could possibly be pending
push {   →  stack: ( [ {
see  }   →  top is { → match ✓ → pop
see  ]   →  top is [ → match ✓ → pop
see  )   →  top is ( → match ✓ → pop     stack empty → valid
```

**The four words that mean "stack":** *matching · nesting · most recent · undo.*

When you see any of them, the answer depends on the **last thing you haven't finished** — and a stack is exactly "the last unfinished thing, on top."

```python
def is_valid(s):
    pairs = {")": "(", "]": "[", "}": "{"}
    stack = []
    for c in s:
        if c in pairs:
            if not stack or stack.pop() != pairs[c]:
                return False
        else:
            stack.append(c)
    return not stack          # ← must be EMPTY, not just "no mismatch"
```

**Gotcha:** `return not stack`, not `return True`. `"((("` never mismatches — it just never closes. That's the case everyone misses.

## ② Technique · Carry the answer with the data

Min Stack — `push`, `pop`, `top`, and `getMin`, all in **O(1)**.

```
1. Obvious way:   getMin scans the stack.        O(n). Fails the requirement.
2. The waste:     I recompute a fact I already knew.
3. What kills it: store the answer ALONGSIDE the value.
```

```
push 5  →  [(5, 5)]                     (value, min-so-far)
push 3  →  [(5,5), (3, 3)]              3 < 5, so new min
push 7  →  [(5,5), (3,3), (7, 3)]       7 > 3, min unchanged
pop     →  [(5,5), (3,3)]               min is instantly stack[-1][1]
```

```python
class MinStack:
    def __init__(self):
        self.stack = []                       # (value, min_so_far)

    def push(self, val):
        cur_min = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, cur_min))

    def pop(self):    self.stack.pop()
    def top(self):    return self.stack[-1][0]
    def getMin(self): return self.stack[-1][1]
```

**The transferable move:** *if a query must be O(1), precompute the answer when you write, not when you read.* This idea comes back in Week 3 for LRU Cache.

## ③ Bonus · A stack shape that isn't a stack

Generate Parentheses. NeetCode files it under Stack; it's actually **backtracking** — a preview of Week 6. Do it anyway, the rule is beautifully simple:

```
add '('  if  open < n           can always open, up to n
add ')'  if  close < open       can only close what's already open
done     if  open == close == n
```

```python
def generate(n):
    out, cur = [], []
    def back(open_, close):
        if open_ == close == n:
            out.append("".join(cur)); return
        if open_ < n:
            cur.append("("); back(open_ + 1, close); cur.pop()   # ← un-choose
        if close < open_:
            cur.append(")"); back(open_, close + 1); cur.pop()
    back(0, 0)
    return out
```

Notice `cur.pop()` after each branch — **choose → explore → un-choose.** Remember that phrase; it's all of Week 6.
