## ① Concept C-08 · Window mechanics

**Anchor:** *"Grow right, shrink left, never look back."*
**Yaad rakho:** *"Right se badhao, left se ghatao — peeche mat dekho."*

Longest substring with no repeating characters, in `"abcabcbb"`.

```
1. Brute force:   every start, every end, check each for dupes.   O(n³)
2. The waste:     "abc" was valid — so I already know "ab" and "bc" are too.
3. What kills it: TWO ENDS — but both moving forward this time.
```

```
a  b  c  a  b  c  b  b
L
R →                        grow R:  a, ab, abc  ✓ valid, len 3
      R
L →                        R hits 'a' again → invalid
   L                       shrink L past the old 'a' → valid again
```

**Both pointers only ever move right.** Each index is touched at most twice — once by `R`, once by `L`. That's what makes it O(n), not O(n²).

### The code

```python
def length_of_longest(s):
    seen = set()
    l = best = 0
    for r in range(len(s)):
        while s[r] in seen:        # invalid → shrink from the left
            seen.remove(s[l])
            l += 1
        seen.add(s[r])             # now valid → record
        best = max(best, r - l + 1)
    return best
```

One `for` (moves `R`) with a `while` inside (moves `L`). **Not two nested for-loops** — that difference is the entire pattern.

**Gotcha:** the inner `while` *looks* like it makes this O(n²). It doesn't, because `l` never resets — it only advances. Say that out loud; interviewers ask it directly.

## ② Warm-up · The one-variable "window"

Best Time to Buy & Sell Stock isn't really a window — but it's the same instinct: **carry one fact forward instead of re-scanning.**

```python
def max_profit(prices):
    cheapest = float("inf")
    best = 0
    for p in prices:
        cheapest = min(cheapest, p)     # best buy seen so far
        best = max(best, p - cheapest)  # sell today?
    return best
```

**The transferable move:** *ask "what single fact, carried forward, removes the inner loop?"* Here it's the cheapest price so far. That question will keep working all year.
