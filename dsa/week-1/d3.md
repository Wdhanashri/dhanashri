## ① Concept C-03 · Prefix / suffix products

**Anchor:** *"Everything left × everything right."*

`[1,2,3,4]` → for each position, the product of every *other* number. No division allowed.

```
1. Brute force:   for each i, multiply all the others.       O(n²)
2. The waste:     I recompute "1×2×3" over and over.
3. What kills it: REUSE — compute the running products once.
```

```
nums:    [ 1,  2,  3,  4]

prefix:  [ 1,  1,  2,  6]     ← product of everything BEFORE i
                ↑ 1        ↑ 1×2×3
suffix:  [24, 12,  4,  1]     ← product of everything AFTER i
           ↑ 2×3×4

answer = prefix[i] × suffix[i]
         [24, 12,  8,  6]
```

### The code — build it in two passes

```python
def product_except_self(nums):
    n = len(nums)
    out = [1] * n

    prefix = 1
    for i in range(n):              # left → right
        out[i] = prefix             # everything BEFORE i
        prefix *= nums[i]

    suffix = 1
    for i in range(n - 1, -1, -1):  # right → left
        out[i] *= suffix            # multiply in everything AFTER i
        suffix *= nums[i]

    return out
```

Read it as: *pass 1 fills in the left side, pass 2 multiplies in the right side.* The output array **is** the scratch space — that's how it stays O(1) extra memory.

**Gotcha:** the obvious "divide the total by nums[i]" dies the instant there's a zero. The two-pass version handles zeros for free, which is exactly why the problem bans division.

**The transferable move:** *when every position needs both sides, sweep once from each direction.*

## ② Technique · Three sets at once

Valid Sudoku. Three rules to check — rows, columns, 3×3 boxes.

```
1. Brute force:   scan rows, then columns, then boxes.  Three passes.
2. The waste:     I touch every cell three times.
3. What kills it: REMEMBER all three, in one pass.
```

The whole problem is **one line** — how to name a box:

```
cols  0 1 2 │ 3 4 5 │ 6 7 8
     ┌──────┼───────┼──────┐
 0-2 │(0,0) │ (0,1) │ (0,2)│      box key = (r // 3, c // 3)
     ├──────┼───────┼──────┤
 3-5 │(1,0) │ (1,1) │ (1,2)│      integer division collapses
     ├──────┼───────┼──────┤      3 rows into 1 box number
 6-8 │(2,0) │ (2,1) │ (2,2)│
     └──────┴───────┴──────┘
```

```python
rows, cols, boxes = defaultdict(set), defaultdict(set), defaultdict(set)

for r in range(9):
    for c in range(9):
        v = board[r][c]
        if v == ".":
            continue
        if v in rows[r] or v in cols[c] or v in boxes[(r//3, c//3)]:
            return False
        rows[r].add(v); cols[c].add(v); boxes[(r//3, c//3)].add(v)
return True
```

**Remember `//` as a grouping tool.** It shows up again in Week 3 for 2D-matrix binary search.
