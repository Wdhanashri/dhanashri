## ① Concept C-04 · Set membership

**Anchor:** *"O(1) 'is it there' — and 'am I a sequence start'."*

A `set` is a dict with the values thrown away. Use it when you only need **"have I seen this?"**

```python
s = set(nums)
if x in s:      # O(1) — instant, no matter how big s is
```

That much you know. Today's real lesson is the second half of the anchor.

## ② The move that makes it linear

**Longest Consecutive Sequence.** `[100, 4, 200, 1, 3, 2]` → answer `4` (that's `1,2,3,4`).

```
1. Brute force:   sort it, then walk.            O(n log n)
2. Can we beat sorting?   Only if we never need full order.
3. What kills it: REMEMBER (a set) — but that alone isn't enough.
```

Here's the trap. The naive set version:

```python
for n in nums:
    length = 1
    while n + length in s:      # walk up from EVERY number
        length += 1
```

For `1,2,3,4` you walk from 1 *and* from 2 *and* from 3 *and* from 4. Quadratic. It passes the small tests, then TLEs.

**The fix is one question: *am I the start?***

```
set = {100, 4, 200, 1, 3, 2}

is 3 a start?  → is 2 in the set?  YES → not a start. SKIP.
is 2 a start?  → is 1 in the set?  YES → not a start. SKIP.
is 1 a start?  → is 0 in the set?  NO  → START! count up: 1,2,3,4 → 4
```

Only sequence *starts* do any walking. Every element is now visited once → **O(n)**.

```python
def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for n in s:
        if n - 1 in s:          # ← the whole problem is this line
            continue            # someone before me will handle this run
        length = 1
        while n + length in s:
            length += 1
        best = max(best, length)
    return best
```

**The transferable move:** *when a loop redoes work, find the one condition that makes each piece of work happen exactly once.*

## ③ Technique · Encoding with a length prefix

Encode a list of strings into one string, then decode it back. Delimiters fail — any character you pick could appear *inside* a word.

```
["neet", "co#de"]

with "#" as separator:   "neet#co#de"   → decodes WRONG (3 words)

with a length prefix:    "4#neet5#co#de"
                          │ │    │ │
                          │ └word└ └word
                          length   length     → unambiguous
```

**Read the number up to the `#`, then take exactly that many characters.** The content can then contain anything at all.

```python
def encode(strs):
    return "".join(f"{len(s)}#{s}" for s in strs)

def decode(s):
    out, i = [], 0
    while i < len(s):
        j = i
        while s[j] != "#":       # read the length digits
            j += 1
        length = int(s[i:j])
        out.append(s[j+1 : j+1+length])
        i = j + 1 + length
    return out
```

**Where this shows up for real:** this is how network protocols frame messages. Worth saying in an interview.
