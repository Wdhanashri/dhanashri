## ① Technique · The computed key

**The idea:** a dict key doesn't have to be a value from the array. **You can invent it.**

`["eat","tea","tan"]` — group the anagrams. Run the ladder:

```
1. Brute force:   compare every word to every other word.   O(n² · k)
2. The waste:     I keep re-comparing letters.
3. What kills it: REMEMBER — but remember by WHAT?
```

The insight: **what makes two words "the same"?** Same letters, same counts. So *make that the key*:

```
"eat" → sorted → "aet"  ┐
"tea" → sorted → "aet"  ├──→ same key → same bucket
"tan" → sorted → "ant"  ┘
```

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)          # missing key → empty list, automatically
    for w in strs:
        key = tuple(sorted(w))          # the invented key
        groups[key].append(w)
    return list(groups.values())
```

**Faster key:** a 26-length count tuple — O(k) instead of O(k log k). Know both, and be ready to say which is faster and why.

**The transferable move:** *find what makes two things equivalent, then make that thing the key.*

## ② Technique · Indexing by count

Top-k frequent elements. Your instinct will say *heap*. Resist it.

```
1. Brute force:   count, then sort by count.        O(n log n)
2. The waste:     sorting gives full order — I only need the top k.
3. What kills it: REMEMBER — but here's the trick, remember BACKWARDS.
```

A count can never exceed `n`. So make the count the **index**:

```
nums = [1,1,1,2,2,3]        counts: {1:3, 2:2, 3:1}

bucket:  [ ] [3] [2] [1] [ ] [ ] [ ]
index:    0   1   2   3   4   5   6
              ↑            ↑
        seen once     seen 3 times

walk from the RIGHT → 1, then 2, then 3.   O(n). No heap.
```

```python
def top_k(nums, k):
    count = Counter(nums)
    bucket = [[] for _ in range(len(nums) + 1)]   # index = frequency
    for num, freq in count.items():
        bucket[freq].append(num)

    out = []
    for freq in range(len(bucket) - 1, 0, -1):    # walk right to left
        for num in bucket[freq]:
            out.append(num)
            if len(out) == k:
                return out
```

**Gotcha:** `bucket` needs `len(nums) + 1` slots — a number can appear all `n` times, and index `n` must exist.

**Say out loud:** *"O(n), no heap."* Interviewers notice when you know this.
