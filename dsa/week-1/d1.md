## ② Concept C-01 · Hash map trade

**Anchor:** *"Spend memory, buy time — a dict kills a nested loop."*

You have `[2, 7, 11, 15]` and target `9`. The obvious way:

```
i=0 (2) → check 7, 11, 15
i=1 (7) → check 11, 15        ← you already looked at these numbers
i=2 (11)→ check 15               once. Why look again?
```

**The waste:** you re-scan numbers you've already walked past. So — remember them instead.

```
walking → 2       seen: {}            need 7. Not there. Remember 2.
walking → 7       seen: {2:0}         need 2. IT'S THERE. Done.
                                      ↑ one pass, no re-scanning
```

### The code

```python
def two_sum(nums, target):
    seen = {}                          # value -> index
    for i, n in enumerate(nums):
        need = target - n              # what would complete the pair?
        if need in seen:               # have I already met it?
            return [seen[need], i]
        seen[n] = i                    # remember me, for someone later
    return []
```

Five lines. Read `need = target - n` as a *question*: **"what am I hoping to find?"** Every dict problem starts with that question.

**Gotcha:** the key is the **value**, the value is the **index**. You look things up *by number*, never by position. Getting this backwards is the #1 Two Sum bug.

**Say out loud:** *"Instead of searching forward, I remember backward."*

## ③ Concept C-02 · Frequency counting

**Anchor:** *"Counter turns 'how many' into one line."*

The moment a problem says **"how many times"**, **"most common"**, or **"same letters"** — you're counting.

```python
from collections import Counter

Counter("aab")             # {'a': 2, 'b': 1}
Counter(s) == Counter(t)   # anagram check, one line
```

Know the manual version too — interviewers ask for it:

```python
count = {}
for c in s:
    count[c] = count.get(c, 0) + 1     # .get(c, 0) = "0 if you've never seen c"
```

**Gotcha:** `Counter` returns `0` for a missing key instead of raising an error. Convenient — but a typo'd key fails silently instead of shouting.
