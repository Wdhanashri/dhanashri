## ① C-50 · State = (index, something you're carrying)

**Anchor:** *"The second dimension can be a running total, a budget, or a mode."*

**This is the step people miss.** They look for a second array, don't find one, and conclude it's 1-D.

### Target Sum

> `dfs(i, total)` = **the number of ways to reach `target` from index `i`, having built `total` so far.**

```
nums = [1,1,1], target = 1

              (0, 0)
            +/      \-
        (1, 1)      (1, -1)
        /   \        /   \
   (2,2)  (2,0)  (2,0)  (2,-2)
                   ▲      ▲
                   └──────┴─ (2, 0) reached TWICE by different paths
                             → cache hit. That's the DP.
```

```python
@cache
def dfs(i, total):
    if i == len(nums):
        return 1 if total == target else 0
    return dfs(i + 1, total + nums[i]) + dfs(i + 1, total - nums[i])
```

**The state is `(i, total)`.** Without `total` in the key, two genuinely different situations share a cache entry — and you get confidently wrong answers rather than a crash.

### Buy & Sell with Cooldown

> `dfs(i, buying)` = **the best profit from day `i`, where `buying` says whether you're allowed to buy.**

```python
@cache
def dfs(i, buying):
    if i >= len(prices):  return 0
    cooldown = dfs(i + 1, buying)                       # do nothing today
    if buying:
        buy = dfs(i + 1, not buying) - prices[i]
        return max(buy, cooldown)
    else:
        sell = dfs(i + 2, not buying) + prices[i]       # ← i+2: the cooldown day
        return max(sell, cooldown)
```

**The second dimension here is a boolean** — a *mode*, not a number. And the cooldown is expressed by `i + 2` instead of `i + 1`. Both are worth noticing: a dimension can be tiny.

**The Gotcha:** everything the answer depends on **must be in the arguments**. If you track `total` in an outer variable and cache on `i` alone, `@cache` returns the first answer it computed for that `i` regardless of the total. The code runs. The answers are wrong. This is the most expensive DP bug there is.

**Recall:** *Name three things the second dimension can be, other than a second array.*
