## ① C-49 · String DP — the two-pointer template

**Anchor:** *"Characters match → advance both. Don't match → try each, take the best."*

**That one line is nearly every string DP problem.**

```
        ""  a  c  e
    ""   0  0  0  0
    a    0  1  1  1        MATCH     → 1 + dp[i+1][j+1]   (diagonal)
    b    0  1  1  1        NO MATCH  → max(dp[i+1][j],    (skip s1's char)
    c    0  1  2  2                        dp[i][j+1])    (skip s2's char)
    d    0  1  2  2
    e    0  1  2  3
```

**Longest Common Subsequence:**
```python
@cache
def lcs(i, j):
    if i == len(s1) or j == len(s2):  return 0
    if s1[i] == s2[j]:
        return 1 + lcs(i + 1, j + 1)              # match: advance BOTH
    return max(lcs(i + 1, j), lcs(i, j + 1))      # skip one or the other
```

**Read the diagram as the code.** Diagonal = match. Left/up = skip one string's character. Every string DP is a variation on which moves are allowed and what they cost.

### Edit distance — the same shape, three moves

```
match     → dp[i+1][j+1]                    free
replace   → 1 + dp[i+1][j+1]                diagonal, costs 1
delete    → 1 + dp[i+1][j]                  skip s1's char
insert    → 1 + dp[i][j+1]                  skip s2's char

dp[i][j] = min of the three when they don't match
```

```python
@cache
def dist(i, j):
    if i == len(w1): return len(w2) - j       # insert what's left
    if j == len(w2): return len(w1) - i       # delete what's left
    if w1[i] == w2[j]:
        return dist(i + 1, j + 1)
    return 1 + min(dist(i+1, j+1),            # replace
                   dist(i+1, j),              # delete
                   dist(i, j+1))              # insert
```

**The base cases carry real meaning here.** Running out of `w1` means you must *insert* everything remaining in `w2` — so the cost is the leftover length, not zero.

**The Gotcha:** the base case is the difference between LCS (returns `0`) and edit distance (returns the **remaining length**). Both are "one string ran out", and they want opposite answers — that's where the English sentence saves you.

**Recall:** *String DP — what do you do on a match, and what are the options on a mismatch?*
