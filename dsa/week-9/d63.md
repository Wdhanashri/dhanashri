## Part C · The transfer test — 20 min ⭐

An unseen problem. **Paper first, in this order:**

> **Given two strings `a` and `b`, return the length of the longest common *substring* (contiguous, unlike a subsequence).**

```
1. dp[i][j] = " ______________________________ "
2. base case(s)
3. the recurrence — what happens on a match? on a MISMATCH?
4. where is the answer?
5. THEN write the memoised version
```

<details><summary>Check — open only after all five</summary>

1. `dp[i][j]` = the length of the longest common substring **ending at** `a[i]` and `b[j]`.
2. Zero when either index runs out.
3. Match → `1 + dp[i-1][j-1]`. **Mismatch → 0**, not the max of neighbours — a substring must be contiguous, so any break resets it.
4. **`max` over the whole table**, not `dp[-1][-1]` — same shape as LIS on D54.
5. —

**The two differences from LCS are the whole problem:** mismatch resets to 0, and the answer is the table max.
</details>

**Pass:** you got the mismatch-resets-to-zero rule and the answer-is-the-max rule **before** looking.

> This is the part that matters. Twelve remembered solutions aren't DP; producing a correct state sentence and recurrence on something new is.
