## ① Interleaving String — pick from one side

> `dfs(i, j)` = **can `s3[i+j:]` be built from `s1[i:]` and `s2[j:]`?**

```
s1 = "aab"   s2 = "dbc"   s3 = "aadbbc"

at each step, the NEXT character of s3 must come from s1 or s2:

   s3[i+j] == s1[i]  →  try taking from s1  →  dfs(i+1, j)
   s3[i+j] == s2[j]  →  try taking from s2  →  dfs(i, j+1)

either works → True
```

```python
@cache
def dfs(i, j):
    if i == len(s1) and j == len(s2):
        return True
    if i < len(s1) and s1[i] == s3[i+j] and dfs(i+1, j):
        return True
    if j < len(s2) and s2[j] == s3[i+j] and dfs(i, j+1):
        return True
    return False
```

**The neat part: `k = i + j`.** You don't need a third dimension — how far you are in `s3` is completely determined by how much you've taken from each source. **Spotting that a third index is redundant is the actual insight**, and it's a good thing to say out loud.

**Quick reject:** `len(s1) + len(s2) != len(s3)` → `False` immediately. Cheap, and interviewers like seeing it.

## ② Distinct Subsequences — match gives you two options

> `dfs(i, j)` = **the number of ways `t[j:]` appears as a subsequence of `s[i:]`.**

```
s = "rabbbit"   t = "rabbit"

when s[i] == t[j], you have TWO choices:
    USE this character   →  dfs(i+1, j+1)
    SKIP it              →  dfs(i+1, j)     ← a later identical char might serve

when they don't match: you can only skip →  dfs(i+1, j)
```

```python
@cache
def dfs(i, j):
    if j == len(t):   return 1          # matched all of t: one full way
    if i == len(s):   return 0          # s exhausted, t isn't: no way

    if s[i] == t[j]:
        return dfs(i+1, j+1) + dfs(i+1, j)     # use it, AND skip it
    return dfs(i+1, j)                          # can only skip
```

**Contrast with LCS:** there, a match meant "take it, advance both" and nothing else. Here a match gives you **both** options, because you're *counting* rather than *maximising* — and the three b's in `"rabbbit"` are exactly why.

**The Gotcha:** the two base cases are asymmetric. `j == len(t)` → **1** (success, one way). `i == len(s)` → **0** (failure). Check `j` first — if both ran out simultaneously that's still a success.

**Recall:** *Distinct Subsequences — on a match, why do you get two branches rather than one?*
