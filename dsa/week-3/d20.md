## ① Warm-up · Carry-based building

Add Two Numbers — digits stored in reverse, add them.

**The shape to notice:** dummy node + a `carry`, and one loop condition that handles every case at once.

```python
def add_two_numbers(l1, l2):
    dummy = ListNode(0)
    cur, carry = dummy, 0
    while l1 or l2 or carry:            # ← all three, in one condition
        total = carry
        if l1: total += l1.val; l1 = l1.next
        if l2: total += l2.val; l2 = l2.next
        carry, digit = divmod(total, 10)
        cur.next = ListNode(digit)
        cur = cur.next
    return dummy.next
```

`while l1 or l2 or carry` removes three separate edge cases: different lengths, and a final carry (`99 + 1`). **Look for the single condition that absorbs the edge cases** — it's a habit worth building.

## ② Technique · Clone with a map

Copy List with Random Pointer — each node also has a `random` pointer to anywhere in the list.

```
1. The problem:  when I clone node A, its random may point to a node
                 I HAVEN'T CLONED YET.
2. The fix:      two passes. Create everything first, wire it up second.
```

```python
def copy_random_list(head):
    old_to_new = {None: None}

    cur = head                                   # pass 1 — just create
    while cur:
        old_to_new[cur] = Node(cur.val)
        cur = cur.next

    cur = head                                   # pass 2 — now wire
    while cur:
        copy = old_to_new[cur]
        copy.next = old_to_new[cur.next]
        copy.random = old_to_new[cur.random]
        cur = cur.next

    return old_to_new[head]
```

**The transferable move:** *when wiring needs things that don't exist yet — create everything first, connect second.* `{None: None}` in the map means you never need a null check.

## ③ The big one · LRU Cache

`get` and `put`, both **O(1)**, evicting the least-recently-used item when full.

```
1. Need O(1) lookup by key         →  dict
2. Need O(1) "move to most recent" →  doubly linked list
3. So: use BOTH. dict maps key → the node itself.

   LRU end                                   MRU end
   [head] ⇄ [ C ] ⇄ [ A ] ⇄ [ B ] ⇄ [tail]
      ↑                                  ↑
   dummy: evict here            dummy: insert here

   dict = { "A": •, "B": •, "C": • }   → pointers straight into the list
```

**Why a doubly linked list:** to remove a node in O(1) you need its *previous* node. Singly linked means scanning to find it — O(n).

**Why dummy head AND dummy tail:** every real node then has both neighbours, so insert and remove never need an edge case. C-18, used twice.

```python
class Node:
    def __init__(self, k, v):
        self.key, self.val = k, v
        self.prev = self.next = None

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}                       # key -> Node
        self.head, self.tail = Node(0,0), Node(0,0)   # dummies
        self.head.next, self.tail.prev = self.tail, self.head

    def _remove(self, node):
        node.prev.next, node.next.prev = node.next, node.prev

    def _insert(self, node):                  # insert just before tail (= most recent)
        prev = self.tail.prev
        prev.next = node; node.prev = prev
        node.next = self.tail; self.tail.prev = node

    def get(self, key):
        if key not in self.cache: return -1
        node = self.cache[key]
        self._remove(node); self._insert(node)        # touch = make most recent
        return node.val

    def put(self, key, value):
        if key in self.cache:
            self._remove(self.cache[key])
        node = Node(key, value)
        self.cache[key] = node
        self._insert(node)
        if len(self.cache) > self.cap:
            lru = self.head.next                      # oldest is next to head
            self._remove(lru)
            del self.cache[lru.key]                   # ← that's why Node stores key
```

**Gotcha:** the node must store its own `key`. On eviction you have the node but need to delete it from the dict — without `node.key` you can't.
