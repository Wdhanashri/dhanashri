## ① Concept C-14 · The template

**Anchor:** *"One template. `while lo <= hi`. Never improvise it."*

Binary search is not a thinking problem. It's a **muscle-memory problem.** Every bug in the world is `<` vs `<=`, or a missing `±1`.

So: stop deriving it. Memorise this exact shape.

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:                     # <=  because lo == hi is a real candidate
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1                # mid is ruled out → +1
        else:
            hi = mid - 1                # mid is ruled out → -1
    return -1
```

**Why each piece is what it is:**

```
lo <= hi      when lo == hi there's still ONE unchecked element.
              Using < skips it. Classic off-by-one.

lo = mid + 1  we just checked mid and it wasn't the answer.
              Writing lo = mid means mid stays in range → INFINITE LOOP.
```

**Gotcha:** if a binary search ever times out, it's `lo = mid` without the `+1`. 90% of the time. Check that first, every time.

## ② Technique · Flatten a 2D grid

Search a 2D Matrix — rows sorted, and each row starts after the previous one ends. So it's really **one sorted array folded up.**

```
[[1,  3,  5,  7],          as one line:
 [10, 11, 16, 20],   →     1 3 5 7 10 11 16 20 23 30 34 60
 [23, 30, 34, 60]]         index 0 .................... 11
```

Binary search indices `0 … m*n-1`, then unfold the index:

```
row = mid // n        n = number of COLUMNS
col = mid  % n

  //  →  which row am I in
  %   →  where in that row
```

```python
def search_matrix(matrix, target):
    m, n = len(matrix), len(matrix[0])
    lo, hi = 0, m * n - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        val = matrix[mid // n][mid % n]
        if val == target: return True
        elif val < target: lo = mid + 1
        else: hi = mid - 1
    return False
```

**`//` and `%` as a pair** — you met `//` for Sudoku boxes on D3. Same tool: *collapse a 2D position into one number, and back.*
