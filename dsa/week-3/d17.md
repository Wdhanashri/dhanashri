## ① Concept C-16 · Rotated arrays

**Anchor:** *"One half is always sorted — find which, then decide."*

```
[4, 5, 6, 7, 0, 1, 2]        a rotated array is just TWO sorted runs
 └── sorted ──┘ └─sorted─┘
```

**The key realisation:** wherever you put `mid`, **at least one side of it is a clean sorted run.** Find which one, then ask a simple question about it.

```
[4, 5, 6, 7, 0, 1, 2]     target = 0
 lo      mid        hi

nums[lo]=4 <= nums[mid]=7   →  LEFT half [4..7] is sorted
is 0 inside [4, 7]?          →  NO   →  discard left, lo = mid + 1

[0, 1, 2]
 lo mid hi                   →  ordinary binary search from here
```

```python
def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid

        if nums[lo] <= nums[mid]:                    # LEFT half is sorted
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:                                        # RIGHT half is sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1
```

**Gotcha:** always reason about the **sorted** half. Asking "is the target in the messy half?" is unanswerable — that's where everybody goes wrong. Check the clean side; if the target isn't there, it must be in the other one.

**The transferable move:** *when data is partly broken, find the part that still obeys the rules and reason only from there.*

## ② Technique · Binary search inside a data structure

Time Based Key-Value Store: `set(key, value, timestamp)`, then `get(key, timestamp)` → the value with the **largest timestamp ≤ the one asked for**.

```
1. Naive:      scan the key's history backwards.        O(n) per get.
2. The waste:  timestamps arrive in increasing order — that's sorted data.
3. What kills it: binary search the history.            O(log n) per get.
```

```python
class TimeMap:
    def __init__(self):
        self.store = defaultdict(list)              # key -> [(timestamp, value)]

    def set(self, key, value, timestamp):
        self.store[key].append((timestamp, value))  # already sorted by time

    def get(self, key, timestamp):
        arr = self.store[key]
        out = ""
        lo, hi = 0, len(arr) - 1
        while lo <= hi:
            mid = (lo + hi) // 2
            if arr[mid][0] <= timestamp:
                out = arr[mid][1]                   # valid — keep it, look for better
                lo = mid + 1
            else:
                hi = mid - 1
        return out
```

**The pattern to notice:** `out = ...` then keep searching. That's the **"largest thing that still qualifies"** shape — you saw it yesterday in Koko (`best = mid`, then narrow). Same skeleton, different question.
