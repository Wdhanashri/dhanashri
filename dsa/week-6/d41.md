## ① C-38 · The Trie

**Anchor:** *"One node per letter. Shared prefixes share nodes."*

```
insert "app", "apple", "bat"

            (root)
            ╱     ╲
          a         b
          │         │
          p         a
          │         │
          p*        t*          * = a word ENDS here
          │
          l
          │
          e*

"app" and "apple" share three nodes. That sharing is the entire point.
```

### The whole structure

```python
class TrieNode:
    def __init__(self):
        self.children = {}          # char -> TrieNode
        self.is_word = False        # ← does a word END here?

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        cur = self.root
        for ch in word:
            if ch not in cur.children:
                cur.children[ch] = TrieNode()
            cur = cur.children[ch]
        cur.is_word = True

    def search(self, word):
        node = self._walk(word)
        return node is not None and node.is_word      # must END there

    def startsWith(self, prefix):
        return self._walk(prefix) is not None          # just needs to EXIST

    def _walk(self, s):
        cur = self.root
        for ch in s:
            if ch not in cur.children:
                return None
            cur = cur.children[ch]
        return cur
```

**`search` vs `startsWith` differ by exactly one condition** — `is_word`. Without that flag, inserting "apple" would make "app" report as a stored word.

**Complexity:** insert and search are **O(length of the word)** — completely independent of how many words are stored. That's the sentence to say.

**The Gotcha:** `is_word` is not optional and it's what people leave out. Prefixes of stored words would otherwise all count as words.

**Recall:** *`search` vs `startsWith` — what one thing differs?*

## ② Wildcards — where backtracking meets the trie

`Design Add and Search Words` allows `.` to match any character.

```
searching "b.d"
             b
           ╱ │ ╲          the '.' means try EVERY child
         a   o   u        → that's backtracking (C-29) inside a trie walk
```

```python
def search(self, word):
    def dfs(i, node):
        for j in range(i, len(word)):
            ch = word[j]
            if ch == ".":
                # try every child, from position j+1
                return any(dfs(j + 1, child) for child in node.children.values())
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_word
    return dfs(0, self.root)
```

**Notice what this is:** an ordinary walk that becomes a branching search the moment it hits a `.`. Two Week-5 and Week-6 ideas meeting — and it's a nice thing to name out loud in an interview.
