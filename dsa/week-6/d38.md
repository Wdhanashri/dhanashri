## ① C-35 · Multi-source BFS

**Anchor:** *"Put every source in the queue before you start. One extra line."*

```
BFS from one source          MULTI-SOURCE BFS
    q = deque([start])           q = deque(all_starts)
         ●                           ●     ●     ●
        ╱│╲                         ╱│╲   ╱│╲   ╱│╲
       ● ● ●                       everything spreads TOGETHER
                                   each cell is reached by its NEAREST source
```

**That's the whole concept.** Seed the queue with all sources; BFS's level-by-level property then gives you *"distance to the nearest source"* for free.

```python
q = deque()
for r in range(rows):
    for c in range(cols):
        if grid[r][c] == 2:          # every rotten orange
            q.append((r, c))
        elif grid[r][c] == 1:
            fresh += 1

minutes = 0
while q and fresh:
    for _ in range(len(q)):          # ← snapshot: one level = one minute (C-22)
        r, c = q.popleft()
        for dr, dc in DIRS:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                grid[nr][nc] = 2
                fresh -= 1
                q.append((nr, nc))
    minutes += 1

return minutes if fresh == 0 else -1
```

**`for _ in range(len(q))` is C-22 from D24** — the level snapshot. Here one level *is* one minute of rotting. Same line, new meaning.

**The Gotcha:** the `and fresh` in the while condition. Without it you run one extra empty level and return `minutes + 1`. And you must return `-1` when fresh oranges remain — unreachable cells are the case everyone forgets.

**Recall:** *Multi-source BFS — what's the single change from ordinary BFS?*

## ② The same shape, twice more

**Walls and Gates** — fill each empty room with the distance to its nearest gate.
> Seed the queue with **every gate**, BFS outwards. Each room is reached first by its closest gate. **Identical to rotting oranges.**

**Pacific Atlantic Water Flow** — cells that can reach *both* oceans.
```
naive:  from every cell, can it reach each ocean?     O(n²) walks
better: start FROM each ocean and walk UPHILL.        two walks total
        answer = the intersection of the two reachable sets
```
**That's the border-inversion move from yesterday**, plus multi-source: seed from the whole ocean edge, not one cell.

**The transferable move worth writing down:** *when "from every cell, can it reach X?" is expensive, start at X and walk backwards.*
