## ① C-32 · The adjacency list

**Anchor:** *"A graph is a dict from node to its neighbours. That's it."*

```
   1 ──── 2          adj = {
   │      │              1: [2, 3],
   3 ──── 4              2: [1, 4],
                         3: [1, 4],
                         4: [2, 3]
                     }
```

```python
from collections import defaultdict

adj = defaultdict(list)
for u, v in edges:
    adj[u].append(v)
    adj[v].append(u)        # ← BOTH directions if undirected. Only one if directed.
```

| | Adjacency list | Adjacency matrix |
|---|---|---|
| Space | O(V + E) | O(V²) |
| "Is there an edge u→v?" | O(degree) | O(1) |
| Use it | **almost always** | dense graphs, or when you need O(1) edge checks |

**The Gotcha:** the single most common graph bug is **adding only one direction on an undirected graph**. It doesn't crash — it silently explores half the graph. Write both `append` lines together, always.

**Recall:** *What is a graph, in one sentence, as a Python data structure?*

## ② C-33 · A grid is a graph

**Anchor:** *"Every cell is a node. Its neighbours are up, down, left, right."*

```
   1 1 0            cell (r,c) connects to
   1 0 0                (r+1,c) (r-1,c) (r,c+1) (r,c-1)
   0 0 1
                    no adjacency list needed — the neighbours are ARITHMETIC
```

**You never build an adjacency list for a grid.** The neighbours are computed:

```python
DIRS = [(1,0), (-1,0), (0,1), (0,-1)]        # write this once, use it all week

def dfs(r, c):
    if r < 0 or c < 0 or r >= rows or c >= cols:  return   # off the board
    if grid[r][c] != "1":                          return   # not land / already done
    grid[r][c] = "0"                                        # mark visited
    for dr, dc in DIRS:
        dfs(r + dr, c + dc)
```

**Number of Islands, entire solution:**
```python
count = 0
for r in range(rows):
    for c in range(cols):
        if grid[r][c] == "1":
            dfs(r, c)          # sink the whole island
            count += 1         # each launch = one island
```

**Read the counting line carefully:** the DFS eats an entire connected component, so the outer loop only *starts* once per island. That's the whole idea.

**The Gotcha:** bounds-check **before** you index. Writing `if grid[r][c] != "1" or r < 0` crashes on the negative index before the bounds test runs — Python's `-1` silently wraps to the last row, which is worse than a crash because it gives wrong answers.

**Recall:** *Number of Islands — why does the outer loop count correctly?*
