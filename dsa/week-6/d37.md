## ① C-34 · The visited set

**Anchor:** *"A tree can't loop back. A graph can — so remember where you've been."*

```
   TREE                        GRAPH
      A                         A ─── B
     ╱ ╲                        │  ╲  │
    B   C                       │   ╳ │
   ╱ ╲                          C ─── D
  D   E
                          A → B → D → C → A → B → …  forever
  every path goes DOWN.
  you can never return.   the ONLY fix: a visited set
```

**That single sentence is the whole of graph traversal.** Everything else you already learned in Week 4.

```python
def dfs(node, visited):
    if node in visited:          # ← the line that doesn't exist in tree DFS
        return
    visited.add(node)
    for nxt in adj[node]:
        dfs(nxt, visited)
```

**Three ways to mark visited — know when each is right:**

| Method | Use when |
|---|---|
| `visited = set()` | general graphs, nodes are hashable |
| Mutate the grid (`"1"` → `"0"`) | grids, and you're allowed to modify the input |
| `visited[r][c]` boolean matrix | grids where the input must stay intact |

**The Gotcha:** add to `visited` when you **enter** a node, not when you leave. Marking on exit lets two branches enter the same node before either finishes — which is an infinite loop with extra steps.

**Recall:** *Why does graph DFS need a visited set when tree DFS doesn't?*

## ② The border trick

Some grid problems are easier **inverted** — instead of finding what's trapped, find what's *free*.

**Surrounded Regions:** flip every `O` not connected to the border.

```
X X X X          don't hunt for surrounded regions.
X O O X          Instead: start from the BORDER, mark everything reachable
X X O X          as safe, then flip whatever is left.
X O X X
   ▲
   this O touches the border → it and its group survive
```

```python
# 1. DFS from every border 'O' → mark them 'T' (temporarily safe)
# 2. Every remaining 'O' is surrounded → flip to 'X'
# 3. Turn every 'T' back into 'O'
```

**The transferable move:** *when "find the trapped ones" is awkward, find the free ones and take the complement.* This same inversion shows up again on D38 in Pacific Atlantic.
